01 / Positioning

既存アプリは「記録帳」で止まっている

Strong / Hevy / FitNote 記録して終わり
記録›履歴を探す›暗算で次を決める
Overload 次の目標まで出す
記録›今日の目標を計算›タップで確定
①漸進的過負荷ナビ

種目を開いた時点で今日の目標が数値で出ている

②入力速度

目標値が入力済み。1セットの記録はタップ1回

02 / Core Logic

ダブルプログレッションで次の目標を決める

← 横にスクロールできます →

例: ベンチプレス(8〜12回 / 刻み 2.5kg)

前回

回数 +1

回数 +1
上限に到達

62.5kg × 8

重量 +2.5kg
回数は下限へ

刻み幅は器具で決まる。バーベル 2.5kg(1.25kg×2枚)、ダンベル 2kg、マシン 5kg。

漸進法は3種類から種目ごとに選べる
