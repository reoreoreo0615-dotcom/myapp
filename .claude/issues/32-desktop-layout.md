## 背景

PC で全画面を確認したところ、レイアウトが画面幅いっぱいに引き伸ばされ、
主要ボタンが 1900px 超の帯になっていた。モバイルファーストで組んだ幅指定
(`w-full`)がデスクトップでもそのまま効いているのが原因。

## 対応内容

- 共通レイアウトにコンテンツ幅の上限を設ける
- 主要ボタンは広い画面で内容に応じた幅にする
- 一覧の操作ボタンを行の右端にそろえる
- 一覧の「削除」を枠線タイプに統一する(確認モーダル内は塗りつぶしのまま)
- フォームの入力欄が間延びしないよう幅を抑える

## 受入条件

- [ ] 1440px 幅で本文が中央に収まり、ボタンが帯にならない
- [ ] 390px 幅の表示が従来どおりで、タップ領域が 44px 以上
- [ ] PHP / JS のテストと Pint・ESLint がすべて通る
