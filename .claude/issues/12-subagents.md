開発体制として、**設計・判断は Opus、確定した仕様の実装は Sonnet サブエージェント**に委譲する構成を整備する。

> 設計ドキュメント: https://claude.ai/code/artifact/960e32f1-ad73-400d-9f21-eddde8965ca0
> (「⑥ 開発体制」セクションの図を参照)

## 委譲の境界

**「判断が要るか」で引く。**

| Opus が持つ | Sonnet に渡す |
| --- | --- |
| スキーマ設計・命名・トレードオフの決定 | マイグレーション・モデルの記述 |
| Issue 分解と受入条件の定義 | 確定した仕様のコード化 |
| レビューと統合 | テストコードの記述 |
| Issue への MD 記録とクローズ | |

## 定義するサブエージェント

`.claude/agents/` に配置。いずれも **model: sonnet** を指定する。

| エージェント | 担当 | 渡す情報 |
| --- | --- | --- |
| `laravel-backend` | マイグレーション / モデル / リレーション / コントローラ / FormRequest / Policy | 確定したスキーマ定義と受入条件 |
| `vue-frontend` | Inertia ページ / Vue コンポーネント / Tailwind スタイル | 画面モックと props の型 |
| `test-writer` | Feature テスト / ProgressionService のユニットテスト | 期待する入出力の表 |

## 各エージェントに読ませる前提

- Laravel 13 / PHP 8.3 の規約
- Laravel Pint の整形ルール(#6 で確定させる)
- 本プロジェクトの設計方針(設計ドキュメント)
- **モバイルファースト**であること(ジムでスマホから使うのが主用途)

## あわせて整備するもの

- [ ] `app/CLAUDE.md` にプロジェクト固有の規約を追記(既存ファイルあり)
- [ ] `.claude/settings.json` に、頻用する読み取り専用コマンドの許可設定

## 受入条件

- [ ] `.claude/agents/` に3つのエージェント定義が置かれている
- [ ] 各定義に model: sonnet と適切なツール制限が設定されている
- [ ] 実際に1つ Issue を委譲して動作確認し、結果をこのIssueにコメントで残す
