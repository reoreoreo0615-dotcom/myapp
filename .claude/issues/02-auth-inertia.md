Laravel 公式スターターキットを使い、認証基盤と Inertia + Vue 3 のフロント基盤を同時に整える。

> 設計ドキュメント: https://claude.ai/code/artifact/960e32f1-ad73-400d-9f21-eddde8965ca0

## 決定事項

| 項目 | 選択 | 理由 |
| --- | --- | --- |
| 認証 | **公式スターターキット**(自前実装しない) | 認証の再発明に時間を使わず本体機能に進むため。コードは手元に展開されるので中身は読める |
| フロント | **Inertia + Vue 3** | フロント技術の市場価値を取る判断。Livewire より学習量は増えるが、その分機能スコープを絞って相殺する |
| CSS | Tailwind CSS v4(導入済み) | |

## 前提

現状の `app/` は素の Laravel 13 スケルトンで、Inertia / Vue は未導入。
スターターキットは `laravel new` 時に選択するものなので、**既存プロジェクトへの後付け手順を調査した上で適用する**。
