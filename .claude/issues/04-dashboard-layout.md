## ダッシュボードに置くタイル(4つ)

| タイル | 内容 | 算出方法 |
| --- | --- | --- |
| 今週の総ボリューム | 例: `12,480 kg` / 先週比 | `SUM(weight * reps)` を `is_warmup = false` に限定して集計 |
| 連続トレーニング | 例: `14 週` | 週単位で1回以上記録がある連続週数 |
| 今月の記録更新 | 例: `3 種目` | 推定1RM が過去最高を更新した種目数 |
| 直近の自己ベスト | 例: `120kg × 5`(デッドリフト・9/3) | 最新の PR レコード |

## 注意点

- **集計は必ず `is_warmup = false` で絞る。**ウォームアップを混ぜると総ボリュームが実態より大きく出る。
- 記録が0件のときの表示を必ず作る(空のタイルではなく「まず1回記録しよう」への導線)。
- 集計クエリは N+1 を避け、集約は SQL 側で行う。
