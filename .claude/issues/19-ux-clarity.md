実機(スマホ)で確認した結果、**使い方が全体的に分かりにくい**というフィードバック。
機能は揃っているが、初見のユーザーが何をすればいいか分からない状態。

ユーザーが挙げた3点すべてに対応する。

---

## ① 記録画面の使い方が伝わらない

### 問題
- メニューを選んだ後、**どこを押せばセットが記録されるのか**が分からない
- **「今日の目標」が何を意味するのか**説明がない。アプリが計算して提示している
  という最重要のコンセプトが伝わっていない

### 対処
- [ ] 「今日の目標」の横に説明を出す。
      例: 「前回 60kg×10 を達成 → 今日は 62.5kg×6 に挑戦」のように
      **前回との関係を1行で示す**。数字だけを置かない
- [ ] 重量アップのときは「**重量が上がりました**」と明示する
      (レップアップとの違いが分かるように)
- [ ] 記録ボタンを、入力欄との関係が分かる配置・ラベルにする
      (「このセットを記録」など、何が起きるか動詞で示す)
- [ ] **初回のみ**、記録画面に短い使い方ガイドを出す(1回閉じたら二度と出さない)
- [ ] セットを記録した直後に、何が起きたかフィードバックを出す
      (「1セット目を記録しました」など)

## ② 用語が難しい

専門用語と略語が説明なしで並んでいる。**筋トレ初心者でも分かる語**に置き換える。

| 現在 | 変更後(案) |
| --- | --- |
| 推定1RM | **推定1RM(1回だけ挙げられる重さの目安)** ※初出時のみ補足 |
| ボリューム / 総ボリューム | **総挙上重量**(または「持ち上げた重さの合計」) |
| `W`(ウォームアップのタグ) | **アップ** |
| ルーティン | **メニュー**(表記を統一。`Admin/Users/Index.vue` に残存) |
| 連続トレーニング | **連続記録** |
| PREV / TARGET などの英語ラベル | 日本語にする |

- [ ] 上記の置き換え
- [ ] 専門用語には**初出時に一言の補足**を付ける(常時表示だとうるさいので、
      ツールチップか小さな注記)
- [ ] `label-micro`(大文字+字間)の英語ラベルが残っていれば日本語にする

## ③ 画面間のつながりが分からない

### 問題
「メニューを作ってから記録する」という順序が分からない。各画面が孤立している。

### 対処
- [ ] **ダッシュボードに「次にやること」の導線を置く。**
      - 進行中のトレーニングがある → 「トレーニングを再開」
      - メニューが0件 → 「まずメニューを作る」
      - メニューがある → 「トレーニングを始める」
- [ ] 各画面の**空状態(0件)から次の行動への導線**を必ず置く
      - メニュー0件 → 「メニューを作成」
      - 履歴0件 → 「まず記録する」
      - 種目未選択(履歴画面)→ 選び方の案内
- [ ] トレーニング終了後、**履歴やダッシュボードへ誘導**する
      (記録して終わり、にしない)
- [ ] メニュー作成画面に、それが何のためのものか1行で説明を置く

## 設計上の注意

- **説明を増やしすぎないこと。** このアプリの差別化軸は「ジムでの入力速度」。
  毎回表示される説明文は邪魔になる。**初回のみ / 空状態のみ / 補足は小さく**が原則
- デザイン方針(`.claude/issues/16-design-foundation.md`)の禁止事項は引き続き厳守
- 375px 幅で横スクロールしないこと

## 受入条件

- [ ] 初見で「メニューを作る → 記録する → 履歴で伸びを見る」の流れが分かる
- [ ] 「今日の目標」が前回との関係で説明されている
- [ ] 専門用語が置き換えられ、初出に補足がある
- [ ] すべての空状態に次の行動への導線がある
- [ ] 初回ガイドは1回閉じたら再表示されない
- [ ] 既存の179テストが壊れていないこと
