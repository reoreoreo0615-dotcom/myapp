## 背景

PC で見たときに「AI が作った感じ」「作りが古い」という印象になっていた。
細線と直角だけで構成した「計器」の方向が、余白の広さと相まって
素っ気なく見えていた。

## 対応内容

iPhone / Mac の標準的な画面(設定アプリ)に近い作りへ寄せる。

- 端末標準の書体(San Francisco / Hiragino)を使う
- 背景は白、情報のまとまりは角丸のカードに載せる
- ボタンは角丸(ピル型)にし、二次操作は淡い面で表す
- タブと期間切り替えはセグメント型にする
- 破壊的な操作の赤と、気づきを促す橙を分ける

## 受入条件

- [ ] 全画面が同じ作り(カード・ボタン・タブ)で統一されている
- [ ] ダークモードでも読める
- [ ] PHP / JS のテストと整形チェックがすべて通る
