デスクトップ幅ではナビゲーションをヘッダーに横並びで置く。スマホは現行の下部固定バーを維持する。

## 現状の問題

`AuthenticatedLayout.vue` はモバイル前提で作られており、**画面幅に関わらず
下部固定バー**になっている。デスクトップでは以下が不自然:

- 幅の広い画面の下端にナビが張り付いていて視線移動が大きい
- ヘッダーが「画面名 + ユーザー名 + ログアウト」だけで空いている
- 下部バーのアイコン+ラベルが、広い画面では間延びして見える

## 方針

**ブレークポイントで出し分ける。**

```
< md (768px未満)   下部固定バー(現行のまま。変更しない)
>= md (768px以上)  ヘッダーに横並び。下部バーは非表示
```

### スマホの下部バーを維持する理由

このアプリはジムで**汗ばんだ手で片手操作**する前提。下部バーは親指の可動域内にあり、
行き先が常に見えている。ハンバーガーは上端にあり目的地が隠れるため、
片手操作では明確に劣る。**モバイル側は現行を維持すること。**

## デスクトップのヘッダー構成

```
+--------------------------------------------------------------+
| Overload   ダッシュボード 記録 履歴 メニュー 管理    reo  ログアウト |
+--------------------------------------------------------------+
|                                                              |
|  画面名(既存の header スロット)                              |
```

- [ ] 左にアプリ名(`ApplicationLogo` + Overload)。ダッシュボードへのリンク
- [ ] 中央〜左寄りにナビ項目を横並び。**現在地をアクセント色の下線で示す**
      (下部バーの `border-t-2` と同じ考え方で、ヘッダーでは `border-b-2`)
- [ ] 右にユーザー名 + ログアウト(既存のものを流用)
- [ ] 「管理」は管理者にのみ表示(既存の `isAdmin` 判定を流用)
- [ ] 下部バーは `md:hidden`、ヘッダーナビは `hidden md:flex`
- [ ] 下部バー非表示時、`body` の `pb-24`(下部バー分の余白)も解除する

## 注意
- **`navItems` の定義は共通のまま使い回すこと。** 2箇所に定義を作らない
- デザイン方針(`.claude/issues/16-design-foundation.md`)の禁止事項を厳守。
  角丸カード・影・グラデーションを使わず、細線と余白で区切る
- 375px / 768px / 1280px の3幅で崩れないこと
- ライト/ダーク両テーマで現在地が判別できること

## 受入条件
- [ ] 768px 以上でヘッダーに横並びナビが出る
- [ ] 768px 未満では現行の下部固定バーのまま(挙動が変わらないこと)
- [ ] 現在地がヘッダー/下部バーの両方で判別できる
- [ ] 「管理」が管理者にのみ出る
- [ ] `navItems` が1箇所で定義されている
- [ ] 既存テストが全て通る
