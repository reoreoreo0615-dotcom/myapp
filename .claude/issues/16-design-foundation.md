## デザイン方向: 計器 / Precision

**体の進捗を測る精密機器としてアプリを設計する。** 数値が主役で、装飾は限界まで削る。
Braun や Teenage Engineering の計測機器の系譜。

現状は Laravel Breeze が生成した汎用スタイルで、「Breeze で作ったアプリ」の見た目になっている。

### 明確に避けるもの(いわゆる「AI実装感」の正体)

これらは**禁止**する。1つでも入ると全体が安っぽくなる。

- 角丸カード(`rounded-lg`)を全面に敷き詰める
- ふわっとしたドロップシャドウ
- 紫〜青のグラデーション
- Inter / Space Grotesk(「無難な選択」の代名詞)
- 見出しに絵文字
- 何でも中央揃え
- 意味のない番号バッジ(01 / 02 / 03)

### 代わりに使うもの

- **カードを使わず細線(hairline)で区切る**
- 影ではなく**罫線と余白**で階層を作る
- 数値は大きく、`tabular-nums` で桁を揃える
- 角丸はほぼゼロ(最大 2px)
- アクセントは**1色だけ**(プレートの青)。多用しない

## デザイントークン

`app/resources/css/app.css` の `@theme` に定義する。
**ダーク基調だが、ライトテーマも完全に定義すること**(OSの設定に従う)。

### 色

```
【ダーク(既定)】              【ライト】
ground   #14171A  地           #F7F8F9
surface  #1B1F23  一段上げる面  #FFFFFF
line     #2A3037  細線         #DFE3E7
ink      #E8EAED  本文         #14171A
ink-2    #9AA3AC  補助         #5A636C
ink-3    #646D77  最も弱い     #8B939C
accent   #4A90D9  プレートの青  #1F5FA9
ok       #4FB783  完了         #2C7A57
warn     #D9784A  停滞・警告    #B0503A
```

**純黒(#000)は使わない。** 「ほぼ黒 + 蛍光色1点」は典型的なAI配色。
わずかに青みを帯びた炭色を地にする。

`ok` / `warn` は**意味を持つ色**であり、アクセントとは別枠。装飾に使わない。

### タイポグラフィ

Google Fonts のみ使用可。

```
英数・数値   Archivo (400/500/600/700)  … tabular-nums を必ず有効化
日本語       Zen Kaku Gothic New (400/500/700)
微細ラベル   JetBrains Mono (400/500)   … TARGET, PREV, SET などの小ラベル
                                          大文字 + letter-spacing 0.1em
```

設計仕様書(`.claude/docs/overload-spec.html`)と同じ組み合わせ。
**ドキュメントとアプリで一貫したブランドになる。**

### 形と余白

```
角丸      最大 2px(実質的に角ばっている)
影        使わない
区切り    1px solid var(--line)
余白      4 / 8 / 12 / 16 / 24 / 32 / 48
タップ領域 最小 44×44px。記録ボタンは高さ 48px
```

## 共通部品(`resources/js/Components/`)

Breeze の既存部品はそのまま使わず、**この方向に合わせて作り直すか新規作成**する。

### 1. `NumberStepper.vue`(最重要)

重量・回数の入力。**ジムで汗だくの指、片手操作**が前提。

```
  −    62.5    +          ← − と + は 44×44px 以上
```

- `props`: `modelValue`, `step`(重量なら 2.5 や 1.25、回数なら 1), `min`, `max`, `unit`
- 中央の数値は直接タップして編集も可能(キーボード入力)
- **長押しで連続増減**(重量を大きく変えるとき用)
- 数値は `tabular-nums`、大きめ(20px以上)

### 2. `TargetDisplay.vue`

```
  TARGET
  62.5 × 8
```

- 小さな大文字ラベル(JetBrains Mono)+ 大きな数値
- **重量が上がったときだけ**アクセント色にする(`type === 'weight'`)
- レップアップのときは通常色。毎回派手にすると「上がった」ことが伝わらない

### 3. `SetRow.vue`

1セット分の行。セット番号 / 重量 / 回数 / 記録ボタン or 完了表示。

- 完了済みは色を落として `✓` を出す
- **二重送信を防ぐ**(送信中はボタンを無効化)

### 4. `StatValue.vue`

ダッシュボードの数値表示。大きな数値 + 単位 + 小ラベル。

### 5. `Rule.vue`

細線の区切り。カードの代わりにこれで情報を区切る。

### 6. ボタン

- `primary` … 記録ボタン。アクセント色、高さ48px
- `ghost` … 枠線のみ
- Breeze の `PrimaryButton` / `SecondaryButton` / `DangerButton` を置き換える
