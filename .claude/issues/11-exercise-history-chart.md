種目ごとの伸びを可視化する。「続けたら強くなっている」を実感させる画面。

> 設計ドキュメント: https://claude.ai/code/artifact/960e32f1-ad73-400d-9f21-eddde8965ca0
> (「④ 画面」セクションの ③ 種目別履歴 のグラフを参照)

## 機能

- [ ] 種目を選ぶと、その種目の全記録を時系列で表示
- [ ] **推定1RM の推移グラフ**(Epley 式 `1RM = W × (1 + R / 30)`)
- [ ] 全セットの一覧(日付 / 重量 / レップ / RPE)
- [ ] 自己ベスト(最大重量・最大推定1RM)の表示
- [ ] 期間フィルタ(直近3ヶ月 / 6ヶ月 / 全期間)

## グラフの注意点

- **のこぎり状になるのが正常。**ダブルプログレッションでは重量を上げた週に推定1RM が一時的に下がる。これをバグと誤認しないこと。設計ドキュメントのグラフが期待される形。
- `is_warmup = false` のセットのみを対象にする。
- データ0件・1件のときに描画が壊れないこと。
- 縦軸のスケールは記録の範囲から動的に決める(0 起点にすると変化が潰れて見えない)。
- ライト / ダーク両テーマで軸ラベルと線が読めること。

## 実装方針

- グラフライブラリを使うか SVG を自前で描くかは実装者判断。ただし**バンドルサイズと学習コストに見合うかを検討し、選定理由をこのIssueにコメントで残すこと。**
- 集計は SQL 側で行い、全レコードを PHP に持ってきてから計算しない。

## 受入条件

- [ ] 種目を選ぶと推定1RM の推移グラフが表示される
- [ ] 全セット一覧が日付降順で表示される
- [ ] 自己ベストが正しく算出される(ウォームアップ除外)
- [ ] 記録0件・1件でも描画が壊れない
- [ ] 両テーマでグラフが読める

## 依存

- #3(DB設計)、ProgressionService(推定1RM 計算)、ワークアウト記録画面(データが入ること)
