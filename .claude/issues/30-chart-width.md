履歴画面の推移グラフが、デスクトップで**画面幅の4割程度しか使っていない**。

## 症状

PC(1280px)で履歴画面を開くと、グラフが左に寄って右側が大きく余る。
記録が8点あってもグラフ自体が小さく、推移が読み取りにくい。

スクリーンショット:
`.claude/docs/screenshots/pc-history.png`

## 原因

`app/resources/js/Components/ExerciseHistoryChart.vue`

```vue
<svg
    :viewBox="`0 0 ${chartWidth} ${chartHeight}`"
    :width="chartWidth"      ← 固定ピクセルで出力されている
    :height="chartHeight"
>
```

`chartWidth` は**点の数から算出した固定値**。SVG に `width` 属性を直接与えているため、
親要素が広くても伸びない。

`overflow-x-auto` のコンテナに入っているのは、**スマホで潰れないよう最小幅を確保する**ため。
その意図は正しいが、デスクトップでの拡大が考慮されていない。

## 対処方針

**スマホでの最小幅は維持したまま、デスクトップでは親幅まで伸ばす。**

```
< 最小幅   … 横スクロール(現行の挙動を維持)
>= 最小幅  … 親要素の幅いっぱいに伸ばす
```

- [ ] `width` / `height` 属性の直接指定をやめ、CSS で `width: 100%` にする
      (`viewBox` があるので比率は保たれる)
- [ ] `min-width` を `chartWidth` に設定し、スマホでの潰れを防ぐ
- [ ] 縦横比が極端にならないよう `chartHeight` の扱いを確認する
      (幅が2倍になっても高さが2倍になると縦長すぎる)
- [ ] **点が2〜3個しかない場合に間延びしないか**確認する
