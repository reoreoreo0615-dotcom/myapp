## 刻み幅(weight_increment)の決め方

器具の物理的制約がそのまま刻み幅になる。「一律 +2.5kg」は現実に合わない。

| 器具 | 刻み | 根拠 |
| --- | --- | --- |
| barbell | 2.50 | 1.25kg プレートを左右に1枚ずつ = 最小単位 |
| dumbbell | 2.00 | 1kg 刻みのダンベルラックを想定(2kg 刻みのジムなら 4.00 に変更) |
| machine | 5.00 | ピン式ウェイトスタックの一般的な刻み |
| cable | 2.50 | |
| bodyweight | 1.25 | 加重ベルトに吊るすプレートの最小単位 |

## レップレンジの決め方

| 種類 | レンジ | 対象 |
| --- | --- | --- |
| コンパウンド(多関節) | 6 – 10 | ベンチプレス、スクワット、デッドリフト、懸垂 等 |
| アイソレーション(単関節) | 10 – 15 | カール、サイドレイズ、レッグエクステンション 等 |

## 投入する種目(主要30種目・部位別)

- **chest** … ベンチプレス / インクラインベンチプレス / ダンベルプレス / インクラインダンベルプレス / チェストプレス / ペックフライ / ディップス
- **back** … デッドリフト / 懸垂 / ラットプルダウン / ベントオーバーロウ / シーテッドロウ / ダンベルロウ
- **shoulders** … ショルダープレス / ダンベルショルダープレス / サイドレイズ / リアレイズ / アップライトロウ
- **legs** … スクワット / レッグプレス / ルーマニアンデッドリフト / レッグエクステンション / レッグカール / カーフレイズ
- **arms** … バーベルカール / ダンベルカール / ハンマーカール / トライセプスプレスダウン / スカルクラッシャー
- **core** … アブローラー / ハンギングレッグレイズ

各種目に `muscle_group` / `movement_type` / `equipment` / `is_bodyweight` / `weight_increment` / `target_rep_min` / `target_rep_max` / `sort_order` を設定する。

## 注意点

- `user_id` は **null**(既定種目)で投入する。
- `movement_type` は MVP では未使用だが、Phase2 の push/pull バランス可視化で使うので**今の時点で正しく入れておく**。後から30件を手で埋め直すのは無駄。
- 懸垂・ディップス・アブローラー・ハンギングレッグレイズは `is_bodyweight = true`。
- シーダーは**冪等**にする(`updateOrCreate` で name をキーに)。再実行で重複しないこと。
