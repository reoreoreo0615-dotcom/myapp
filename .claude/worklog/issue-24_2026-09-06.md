## 4つの判断とその根拠

### ① 停滞判定は回数ベース(直近3セッション)
「3週間」という期間ベースは**頻度で意味が変わる**ため不採用。
週1回の種目と週3回の種目では、同じ3週間でも試行回数が3倍違う。
回数ベースなら実施頻度によらず同じ試行回数を基準にできる。

### ② 「横ばい」と「下がっている」を区別する
直近N回の**隣接するすべてのペアが厳密に下降し続けている**場合のみ `declining`。
横ばいが1区間でも混じれば `stagnant`。

例: 60 → 60 → 55 は「連続した下降」ではないので `stagnant` 扱い。
**体調不良の1回を「下降傾向」と断定しない。**

### ③ 部位バランスの指標はセット数
総挙上重量だと**脚種目が過大に見え、本題である push/pull の偏りがぼやける**
(スクワット1セットの重量はサイドレイズ1セットの何倍にもなる)。
セット数は種目間で公平。

### ④ 閾値は 1.5倍、最低10セット、直近4週間
1.5 は「概ね 1:1、緩めても 1:1.5 程度まで」という一般的な指導目安。
push+pull 合計10セット未満は判定しない(数セットで比率を語らない)。

## 実データでの検証(Opus が実行)

```
停滞種目: 0件

部位バランス:
  push 40 / pull 12 / legs 24 / core 0
  ratio 3.33  isImbalanced: true  dominant: push
```

**誤検出ゼロ。** ベンチプレスは9セッションで 57.5kg → 62.5kg と順調に伸びており
正しく「停滞なし」。3セッションしかない種目は N+1=4 未満のため未判定。

**部位バランスは push:pull = 3.33:1 の明確な偏りを検出した。**
これは仕様書が懸念していた「ベンチプレス中心で push 過多」のケースそのもので、
実データで機能が意図どおり働くことが確認できた。
