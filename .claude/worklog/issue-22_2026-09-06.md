## 実装内容
デスクトップ幅(768px以上)でナビをヘッダーに横並び表示し、下部固定バーを隠す。
スマホ(768px未満)は現行の下部固定バーを維持。

## 変更ファイル
- `app/resources/js/Layouts/AuthenticatedLayout.vue`(唯一の変更)

## 実装

```
< md   下部固定バー(md:hidden で md 以上は非表示)
>= md  ヘッダーに横並び(hidden md:flex)
```

- 外側 `div` を `pb-24` → `pb-24 md:pb-0`(デスクトップで下部バー分の余白を解除)
- 現在地: 下部バーは `border-t-2`、ヘッダーは `border-b-2` でアクセント色
- `aria-current="page"` を付与
- 左に `ApplicationLogo` + Overload(ダッシュボードへリンク)

**下部バーのマークアップは一切変更していない**(アイコンSVG、`border-t-2`、
`min-h-[56px]` 等すべて維持)。スマホの挙動は変わらない。

## navItems の共有
定義は `computed` 1箇所のまま。ヘッダーと下部バーの両方が同じ `navItems` を
`v-for` で参照する。検証: 定義1箇所 / 参照2箇所。
項目を追加したとき片方だけ更新されてズレることがない。

## 設計上の判断(指定と異なる点)

Issue のアスキーアートでは「ロゴ・ナビ・ユーザー名・ログアウト」を**1段**で
描いていたが、実装は**2段構成**になっている。

```
1段目  ロゴ + ナビ項目          (md以上のみ)
2段目  画面名 + ユーザー名 + ログアウト  (全幅共通)
```

理由: 既存の「画面名スロット + ユーザー名 + ログアウト」の行を作り変えると、
ログアウトのマークアップを複製することになるため。複製を避ける判断としては妥当。

**トレードオフ:** デスクトップでヘッダーが2段になり、縦方向を消費する。
1段にまとめたい場合は別途調整が必要。
